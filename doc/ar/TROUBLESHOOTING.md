# حل المشكلات

| العَرَض | ما يجب التحقق منه |
| --- | --- |
| لم يتم العثور على `agentboard` | أعد تشغيل PowerShell بعد Scoop. عند التثبيت من ملف ZIP، استخدم المسار الكامل إلى `agentboard.exe`. |
| صفحة ويب تعرض الواجهة القديمة بعد الإنشاء | أوقف تشغيل الخادم Ctrl+C. قم بتنفيذ `./scripts/build.ps1`، وقم بتشغيل ثنائي جديد. يجب أن يتم إنشاء Vite قبل Go لأن الواجهة مدمجة في ملف EXE. تحديث الصفحة Ctrl+F5. |
| المنفذ 7337 مشغول | قد يكون AgentBoard قيد التشغيل بالفعل. افتح `http://127.0.0.1:7337` أو قم بإنهاء العملية القديمة. بالنسبة للمنافذ الأخرى، استخدم `--addr`. |
| لم يتم العثور على المشروع | في المجلد المطلوب، قم بتنفيذ `agentboard init`. ثم `agentboard open` منه أو `agentboard open C:\путь\к\проекту`. |
| العامل لا يرى المهمة | يجب تعيين المهمة إلى هذا العامل المعين ويجب أن تكون موجودة في `Features` أو `In progress` أو `Testing` أو `Verification`. لا يرى الذكاء الاصطناعي `Backlog` و`Complete` والأعمدة المخصصة. |
| يوجد فحص خادم MCP، لكن العميل غير متصل | لا يتحقق فحص الخادم من إعدادات العميل الخارجي. أعد تشغيل العميل، وتحقق من ملف التكوين الخاص به، والمسار إلى `agentboard.exe`، و`--project`، و`--worker`، و`--db` العام. اطلب الاتصال بـ `get_my_board`. |
| عامل غير متصل | ربما يكون العميل قد أنهى الخدمة أو ربما لم يبدأ تشغيل MCP بعد. بعد 90 ثانية من عدم نبض القلب، تعتبر الجلسة غير متصلة. |
| ملف JSON لا يستورد | تحقق من `version: 1`، و`title` المطلوب، وعمال `Slug` الحاليين وأسماء الممتلكات. لا يسمح JSON بالتعليقات أو الفواصل الزائدة. |
| غير قادر على إعادة بناء `agentboard.exe` | لا يمكن لـ Windows استبدال ملف EXE قيد التشغيل. أوقف الخادم Ctrl+C وحاول الإنشاء مرة أخرى. |
| اختفت المهام بعد التحديث | تأكد من أن `--db` لا يشير إلى ملف آخر وأنك قمت بتسجيل الدخول بنفس مستخدم Windows. القاعدة الافتراضية موجودة في `%AppData%\AgentBoard`. |

إذا لم يتم وصف الخطأ، فاجمع النص الدقيق للرسالة وإصدارات `agentboard version` وWindows والخطوات اللازمة لإعادة المحاولة. لا تنشر بيانات المشروع الخاص أو محتويات قاعدة البيانات في إصدار مفتوح.
