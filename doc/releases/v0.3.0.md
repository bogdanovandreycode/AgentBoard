AgentBoard 0.3.0 adds image and file attachments to task descriptions and comments, with full support for AI workers over MCP.

## Added

- Separate **Images** and **Files** buttons in the Markdown editor, with multiple file selection, drag and drop, and clipboard screenshot paste.
- Numbered image links and document links inside Markdown, with compact attachment lists below descriptions and comments.
- Image preview dialogs with download and **Show in folder** actions. File attachments can also be downloaded or revealed in the local file manager.
- Lossless WebP conversion for screenshots, including transparency. Images are limited to 20 MiB and 20 million pixels; other files retain their original bytes and support any file type up to 50 MiB.
- Native image content in the MCP `get_task` response, plus `get_image` for individual screenshots. Large image sets include instructions for retrieving omitted previews.
- MCP `upload_image`, `upload_file`, and `get_file` tools. AI workers can attach their own screenshots and files to comments, and read file attachments in bounded UTF-8 or base64 chunks.

## Improved

- Comments now render Markdown and keep their draft and attachments if submission fails.
- Save and send actions wait for attachment uploads to finish.
- Board summaries show readable attachment labels instead of raw storage URLs.
- Attachment access follows task ownership and workflow visibility. Images and files from other workers, Backlog, and Complete cannot be accessed through worker MCP tools.
- Updated Vite and `source-map-js` to compatible patched versions to resolve the frontend build dependency advisories found during release checks.

## Storage and upgrading

- Images are stored in the `images` folder and other attachments in the `files` folder beside the AgentBoard database. SQLite stores references and metadata rather than attachment bytes.
- With the default Windows configuration, these folders are under `%AppData%\AgentBoard`. A custom `--db` keeps attachments beside the selected database.
- Existing databases are migrated automatically. Back up the database together with both attachment folders.
- Restart AgentBoard and reconnect MCP clients after upgrading. Refresh an already-open browser tab to load the new editor controls.
