# Почніть тут

## Що таке AgentBoard

Подайте звичайну дошку з картками завдань. Ви створюєте завдання, призначаєте відповідального та спостерігаєте за роботою. Воркери AI отримують лише призначені ним завдання через MCP та повідомляють про хід роботи. Ви вирішуєте, коли завдання готове остаточно.

**Проект** — папка на комп'ютері та окрема дошка. **Завдання** — картка з описом, відповідальним та етапом. **Воркер** - логічне ім'я AI-клієнта. **MCP** — спосіб, яким AI-клієнт підключається до AgentBoard. **Scoop** — менеджер інсталяції програм для Windows.

Код не потрібно писати. Потрібні Windows, браузер, PowerShell і для роботи AI, встановлений AI-клієнт з підтримкою локальних MCP-серверів.

## Перший запуск

1. Встановіть програму за інструкцією ](INSTALL.md).
2. Створіть у Провіднику папку проекту, наприклад, `C:\Projects\MyFirstProject`.
3. Відкрийте папку у Провіднику. Клацніть в рядку адреси, введіть `powershell` і натисніть Enter.
4. У вікні виконайте:

```powershell
agentboard init
agentboard open
```

5. Відкриється браузер із адресою `http://127.0.0.1:7337`. Залишіть вікно PowerShell відкритим, доки використовуєте дошку. Закриття вікна зупинить локальний сервер, але завдання збережеться.

Якщо команду `agentboard` не знайдено, закрийте PowerShell та відкрийте знову після встановлення Scoop. При установці із ZIP використовуйте повний шлях до `agentboard.exe`.

## Перше завдання

Натисніть **New task**, заповніть **Title**, за потреби **Description**, потім **Save**. Нове завдання в `Backlog` доступне людині. Щоб AI приступив до роботи, призначте воркера та перенесіть завдання до `Features`. Покроковий опис полів - [TASKS.md](TASKS.md).

## Перший воркер

Відкрийте **Workers → Add worker**. Виберіть AI-клієнт (наприклад, Codex або Claude Code), перевірте ім'я та короткий ідентифікатор `Slug`, натисніть **Save**. Відкрийте створеного воркера: є MCP-конфігурація, кнопка копіювання і перевірка сервера. Скопіюйте конфігурацію в AI-клієнт згідно [WORKERS_MCP.md](WORKERS_MCP.md). Після підключення попросіть клієнта викликати `get_my_board`.
