# Робота із завданнями

## Додати завдання

На вкладці **Board** натисніть **New task**. Заповніть назву та опис. Опис та інструкції тестування підтримують Markdown: виділіть текст та використовуйте панель форматування для жирного, курсиву, посилання та списку. Натисніть **Save**.

Поля:

| Поле | Що означає |
| --- | --- |
| Title | Коротка назва задачі. |
| Description | Що треба зробити і як зрозуміти, що робота готова. |
| держава | Етап роботи; нова задача зазвичай починається в `Backlog`. |
| Priority | `critical`, `high`, `medium` або `low`. |
| Responsible | Людина, конкретний воркер або призначення. |
| Testing mode `AI` - перевіряє AI; `Human` - перевіряє людина; `Hybrid` - обидва. |
| Dependencies | Завдання, які мають бути виконані раніше. |
| AI/Human test instructions | Вказівки відповідного перевіряючого. |
| Custom properties | Додаткові поля створені у вкладці **Properties**. |

Для AI завдання спочатку створіть воркера, виберіть його в Responsible, потім перенесіть картку в `Features`. AI бачить лише призначені йому завдання на чотирьох етапах від `Features` до `Verification`.

## Пересунути завдання

Перетягніть картку між колонками. Можна переключитися між видом «всі колонки» і широкими колонками з горизонтальним прокручуванням. `Backlog` та `Complete` керуються людиною. AI може просувати завдання лише `Features → In progress → Testing → Verification` через спеціальні MCP-інструменти. Завдання з невиконаним ручним тестуванням не має пройти AI-перевірку.

## Картка завдання

Натисніть картку, щоб побачити опис, відповідального, тестові інструкції та вкладки історії, тестів, артефактів та витрат AI. **Edit task** змінює зміст. Коментар людини додається до спільної історії. Пошук у верхніх фільтрах шукає за назвою, описом, ID та воркером; окрема кнопка відкриває великий пошук.

## Колонки та властивості

У вкладці **Settings** можна змінювати порядок доступних людині колонок та додавати свої. Чотири етапи AI фіксовані та йдуть у колишньому порядку. Колонка користувача - місце для відкладених людиною завдань: для AI таке завдання має стан `Backlog`. При видаленні колонки її завдання повертаються до звичайного `Backlog`.

У вкладці **Properties** можна додати поля типу текст, число, прапор, дата, вибір та URL. `Human only` приховує поле від AI; `Agent read` дозволяє читання, `Agent read/write` також дозволяє запис через підтримувані інструменти. Не змінює права AI на етапи завдання.
