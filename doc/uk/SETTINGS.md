# Налаштування

Відкрийте пункт **Settings** у бічному меню вибраного проекту. Зміни зберігаються кнопкою **Save settings** та зберігаються для проекту в базі AgentBoard.

## Мова та зовнішній вигляд

Поле **Language** відкриває список, що розкривається, з пошуком. За замовчуванням вибрано варіант **Follow system**, який бере мову браузера. Доступні мови зі скріншотів: арабська, португальська (Бразилія), китайська спрощена, чеська, датська, нідерландська, англійська, фінська, французька, німецька, італійська, японська, корейська, норвезька букмол, польська, російська, іспанська, шведська; додатково білоруська, румунська та болгарська. **Follow system** бере мову браузера. Основні підписи переведені вручну, решта рядків UI має попередній автоматичний переклад. Перед громадським релізом бажано віднімати переклади носіями мов; назви клієнта, команди, JSON-поля та дані користувача залишаються без перекладу.

**Color scheme**: Dark (вихідна тема), Light, Black, Ubuntu та Windows. **Time zone** керує відображенням дат; дані продовжують зберігатися в UTC. **System time zone** використовує налаштування комп'ютера.

## Колонки

Чотири етапи `Features`, `In progress`, `Testing`, `Verification` закріплені в цьому порядку: їх не можна перейменувати або видалити. Інші колонки можна переставити доступними стрілками. Введіть назву та натисніть **Add column**, щоб створити власну колонку. Вона призначена для задач людини: AI бачить таке завдання як `Backlog` і не отримує через MCP. Видалення колонки при збереженні переносить її завдання у стандартний `Backlog`.

## Веб та MCP

**Board refresh** задає частоту оновлення дошки та карток за секунди (1–60). **Worker refresh** оновлює статус воркерів (2-120 секунд). Це опитування веб-інтерфейсу, а не частота запуску AI. Воркери не запускаються автоматично.

Адреса веб-сервера задається під час запуску CLI, наприклад `agentboard open --addr 127.0.0.1:7444`. Для зміни адреси сервер потрібно перезапустити. За промовчанням використовується `127.0.0.1:7337`. MCP працює через окрему локальну команду `agentboard mcp --project ... --worker ...` та не залежить від веб-порту. Для нестандартної бази вкажіть однаковий `--db` у всіх командах. Конфігурацію кожного клієнта копіюйте із картки воркера.
