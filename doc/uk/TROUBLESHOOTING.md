# Вирішення проблем

| Симптом Що перевірити.
| --- | --- |
| `agentboard` не знайдено | Перезапустіть PowerShell після Scoop. При установці із ZIP використовуйте повний шлях до `agentboard.exe`. |
| Веб-сторінка показує старий інтерфейс після збирання | Зупиніть запущений сервер Ctrl+C. Виконайте `./scripts/build.ps1`, запустіть новий бінарник. Vite повинен зібратися до Go, тому що інтерфейс вбудований у EXE. Оновіть сторінку Ctrl+F5. |
| Порт 7337 зайнятий | Можливо, AgentBoard вже працює. Відкрийте `http://127.0.0.1:7337` або завершіть старий процес. Для іншого порту використовуйте `--addr`. |
| Проект не знайдено У потрібній папці виконайте `agentboard init`. Потім `agentboard open` з неї або `agentboard open C:\путь\к\проекту`. |
| Воркер не бачить завдання Завдання має бути призначене саме цьому воркеру і перебувати в `Features`, `In progress`, `Testing` або `Verification`. `Backlog`, `Complete` і колонки AI не бачить. |
| MCP server check є, а клієнт не підключений Перевірка сервера не перевіряє налаштування зовнішнього клієнта. Перезапустіть клієнт, перевірте його конфігураційний файл, шлях до `agentboard.exe`, `--project`, `--worker` та загальний `--db`. Попросіть викликати `get_my_board`. |
| Воркер Offline | Клієнт міг завершитись або ще не запускав MCP. Після 90 секунд без heartbeat сесія вважається відключеною. |
| Файл JSON не імпортується Перевірте `version: 1`, обов'язковий `title`, існуючі `Slug` воркерів та імена властивостей. JSON не допускає коментарі та завершальні коми. |
| Не вдалося перезбирати `agentboard.exe` | Windows не може замінити запущений EXE. Зупиніть сервер Ctrl+C і повторіть складання. |
| Завдання пропали після поновлення | Перевірте, що `--db` не вказує на інший файл і ви увійшли під тим самим користувачем Windows. Стандартна база знаходиться в `%AppData%\AgentBoard`. |

Якщо помилка не описана, зберіть точний текст повідомлення, версії `agentboard version` та Windows, а також дії для повторення. Не публікуйте приватні дані проекту або вмісту бази у відкритому issue.
