# Импортиране на задачи от JSON

Разделът **Задачи за импортиране** приема JSON файл в UTF-8 кодиране. Използвайте го, ако прехвърляте задачи от друга услуга. Щракнете върху **Изтегляне на JSON шаблон**: Шаблонът включва текущите персонализирани имена на свойства и `Slug` на наличния работник за този проект.

## Стъпка по стъпка

1. Създайте необходимите работници (**Workers**) и свойства (**Properties**) преди импортиране.
2. Изтеглете шаблона, отворете го в текстов редактор, заменете примерите със собствени задачи и запазете файла с разширение `.json`.
3. В раздела **Задачи за импортиране** изберете файл. Интерфейсът ще покаже броя на задачите.
4. Щракнете върху **Импортиране на задачи**. Сървърът ще провери целия файл: ако бъде открита грешка, нито една задача от него няма да бъде написана. Коригирайте съобщението за грешка и опитайте отново.

Минимален файл:

```json
{
  "version": 1,
  "tasks": [
    { "title": "Plan the project" },
    { "title": "Review the result", "state": "features", "priority": "high" }
  ]
}
```

Пример с работник, собственост и зависимост:

```json
{
  "version": 1,
  "tasks": [
    {
      "key": "design",
      "title": "Prepare the design",
      "description": "## Goal\nPrepare the home page mockup.",
      "state": "features",
      "priority": "high",
      "testing_mode": "hybrid",
      "assignee": { "type": "worker", "worker": "codex" },
      "ai_test_instructions": "Check the build.",
      "human_test_instructions": "Review the page in a browser.",
      "properties": { "Department": "Design" }
    },
    {
      "title": "Approve the design",
      "depends_on": ["design"],
      "assignee": { "type": "human" }
    }
  ]
}
```

`version` трябва да бъде `1`, масив `tasks` - от 1 до 1000 задачи. Изисква се `title`. Валидни етапи: `backlog`, `features`, `in_progress`, `testing`, `verification`, `complete`. Приоритети: `critical`, `high`, `medium`, `low`; тестови режими: `ai`, `human`, `hybrid`. Отговорен: `unassigned`, `human` или `worker` със съществуващ `worker` (Slug или ID). `properties` използва имената или идентификаторите на вече създадени свойства. `key` е уникален във файла; `depends_on` се отнася за такива ключове. Сървърът сам създава идентификатори на задачи.

Повторното импортиране на същия файл ще създаде нови проблеми, така че проверете дъската, преди да щракнете отново. Когато се импортират, задачите се записват като създадени от хора; В хронологията се появява системен запис.
