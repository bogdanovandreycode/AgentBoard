# Рашэнне праблем

| Сімптом | Што праверыць |
| --- | --- |
| `agentboard` не знойдзены | Перазапусціце PowerShell пасля Scoop. Пры ўстаноўцы з ZIP выкарыстоўвайце поўны шлях да `agentboard.exe`. |
| Вэб-старонка паказвае стары інтэрфейс пасля зборкі Спыніце запушчаны сервер Ctrl+C. Выканайце `./scripts/build.ps1`, запусціце новы бінарнік. Vite павінен сабрацца да Go, таму што інтэрфейс убудаваны ў EXE. Абнавіце старонку Ctrl+F5. |
| Порт 7337 заняты | Магчыма, AgentBoard ужо працуе. Адкрыйце `http://127.0.0.1:7337` або завяршыце стары працэс. Для іншага порта выкарыстоўвайце `--addr`. |
| Праект не знойдзены | У патрэбнай тэчцы выканайце `agentboard init`. Затым `agentboard open` з яе ці `agentboard open C:\путь\к\проекту`. |
| Воркер не бачыць задачы Задача павінна быць прызначаная менавіта гэтаму воркеру і знаходзіцца ў `Features`, `In progress`, `Testing` ці `Verification`. `Backlog`, `Complete` і прыстасаваныя калонкі AI не бачыць. |
| MCP server check ёсць, а кліент не падлучаны Праверка сервера не правярае налады знешняга кліента. Перазапусціце кліент, праверце яго канфігурацыйны файл, шлях да `agentboard.exe`, `--project`, `--worker` і агульны `--db`. Папытаеце выклікаць `get_my_board`. |
| Воркер Offline | Кліент мог завяршыцца ці яшчэ не запускаў MCP. Пасля 90 секунд без heartbeat сесія лічыцца адключанай. |
| Файл JSON не імпартуецца Праверце `version: 1`, абавязковы `title`, якія існуюць `Slug` воркераў і імёны уласцівасцяў. JSON не дапускае каментары і завяршальныя коскі. |
| Не атрымоўваецца перасабраць `agentboard.exe` | Windows не можа замяніць запушчаны EXE. Спыніце сервер Ctrl+C і паспрабуйце зборку. |
| Задачы зніклі пасля абнаўлення Праверце, што `--db` не паказвае на іншы файл і вы ўвайшлі пад тым жа карыстачом Windows. База па змаўчанні знаходзіцца ў `%AppData%\AgentBoard`. |

Калі памылка не апісана, збярыце дакладны тэкст паведамлення, версіі `agentboard version` і Windows, а таксама дзеянні для паўтарэння. Не публікуйце прыватныя дадзеныя праекту або змесціва базы ў адкрытым issue.
