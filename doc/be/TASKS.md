# Праца з задачамі

## Дадаць задачу

На ўкладцы **Board** націсніце **New task**. Запоўніце назву і апісанне. Апісанне і інструкцыі тэсціравання падтрымліваюць Markdown: вылучыце тэкст і выкарыстоўвайце панэль фарматавання для тоўстага, курсіва, спасылкі і спісу. Націсніце **Save**.

Палі:

| Поле | Што азначае |
| --- | --- |
| Title | Кароткі назоў задачы. |
| Description | Што трэба зрабіць і як зразумець, што праца гатова. |
| State | Этап працы; новая задача звычайна пачынаецца ў `Backlog`. |
| Priority | `critical`, `high`, `medium` або `low`. |
| Responsible | Чалавек, канкрэтны воркер ці без прызначэння. |
| Testing mode | `AI` - правярае AI; `Human` - правярае чалавек; `Hybrid` - абодва. |
| Dependencies | Задачы, якія павінны быць выкананы раней. |
| AI/Human test instructions | Указанні адпаведнаму правяральшчыку. |
| Custom properties | Дадатковыя палі, створаныя ва ўкладцы **Properties**. |

Для AI-задачы спачатку стварыце воркера, абярыце яго ў Responsible, затым перанясіце картку ў `Features`. AI бачыць толькі прызначаныя яму задачы на ​​чатырох этапах ад `Features` да `Verification`.

## Перасунуць задачу

Перацягнуць картку паміж калонкамі. Можна пераключыцца паміж выглядам усе калонкі і шырокімі калонкамі з гарызантальнай пракруткай. `Backlog` і `Complete` кіруюцца чалавекам. AI можа прасоўваць задачу толькі `Features → In progress → Testing → Verification` праз спецыяльныя MCP-інструменты. Задача з нявыкананым ручным тэсціраваннем не павінна прайсці AI-праверку.

## Картка задачы

Націсніце картку, каб убачыць апісанне, адказнага, тэставыя інструкцыі і ўкладкі гісторыі, тэстаў, артэфактаў і затрат AI. **Edit task** мяняе змест. Каментар чалавека дадаецца да агульнай гісторыі. Пошук у верхніх фільтрах шукае па назове, апісанні, ID і воркеру; асобная кнопка адчыняе вялікі пошук.

## Калонкі і ўласцівасці

Ва ўкладцы **Settings** можна мяняць парадак даступных чалавеку калонак і дадаваць свае. Чатыры этапы AI фіксаваны і ідуць у ранейшым парадку. Карыстальніцкая калонка - месца для адкладзеных чалавекам задач: для AI такая задача мае стан `Backlog`. Пры выдаленні калонкі яе задачы вяртаюцца ў звычайны `Backlog`.

Ва ўкладцы **Properties** можна дадаць палі тыпу тэкст, лік, сцяг, дата, выбар і URL. `Human only` хавае поле ад AI; `Agent read` дазваляе чытанне, `Agent read/write` таксама дазваляе запіс праз падтрымоўваныя прылады. Гэта не мяняе правы AI на этапы задачы.
