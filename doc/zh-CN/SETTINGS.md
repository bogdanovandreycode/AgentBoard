# 设置

在所选项目的侧面菜单中打开**设置**。使用 **保存设置** 按钮保存更改，并将项目存储在 AgentBoard 数据库中。

## 语言和外表

**语言** 字段将打开一个搜索下拉列表。默认情况下，选择 **跟随系统** 选项，该选项采用浏览器语言。屏幕截图中可用的语言：阿拉伯语、葡萄牙语（巴西）、简体中文、捷克语、丹麦语、荷兰语、英语、芬兰语、法语、德语、意大利语、日语、韩语、挪威博克马尔语、波兰语、俄语、西班牙语、瑞典语、土耳其语、乌克兰语、越南语；另外还有白俄罗斯语、罗马尼亚语和保加利亚语。 **关注系统**采用浏览器语言。主要签名是手动翻译的，其余 UI 行有初步的自动翻译。在公开发布之前，建议由母语人士校对翻译；客户端名称、命令、JSON 字段和用户数据保持不变，无需翻译。

**配色方案**：深色（原始主题）、浅色、黑色、Ubuntu 和 Windows。 **时区**控制日期的显示；数据继续以 UTC 存储。 **系统时区**使用计算机设置。

## 列

四个阶段 `Features`、`In progress`、`Testing`、`Verification` 的顺序是固定的：它们不能重命名或删除。其他列可以使用可用的箭头重新排列。输入名称并单击“**添加列**”以创建自定义列。它是为人类任务而设计的：AI 看到像 `Backlog` 这样的任务，但不会通过 MCP 接收它。保存时删除列会将其任务转移到常规 `Backlog`。

## 网络和 MCP

**板刷新** 设置板和卡的刷新率，以秒为单位 (1–60)。 **工作人员刷新**更新工作人员的状态（2-120 秒）。这是Web界面轮询，而不是AI触发频率。工作人员不会自动启动。

Web 服务器地址在启动 CLI 时设置，例如 `agentboard open --addr 127.0.0.1:7444`。要更改地址，必须重新启动服务器。默认为 `127.0.0.1:7337`。 MCP 通过单独的本地命令 `agentboard mcp --project ... --worker ...` 进行操作，并且独立于 Web 端口。对于非标准底座，所有命令中指定相同的`--db`。从工作卡复制每个客户端的配置。
