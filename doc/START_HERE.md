# Начните здесь

## Что такое AgentBoard

Представьте обычную доску с карточками задач. Вы создаёте задачи, назначаете ответственного и наблюдаете за работой. Воркеры AI получают только назначенные им задачи через MCP и сообщают о ходе работы. Вы решаете, когда задача готова окончательно.

**Проект** — папка на компьютере и отдельная доска. **Задача** — карточка с описанием, ответственным и этапом. **Воркер** — логическое имя AI-клиента. **MCP** — способ, которым AI-клиент подключается к AgentBoard. **Scoop** — менеджер установки программ для Windows.

Код писать не требуется. Нужны Windows, браузер, PowerShell и, для работы AI, установленный AI-клиент с поддержкой локальных MCP-серверов.

## Первый запуск

1. Установите приложение по [инструкции](INSTALL.md).
2. Создайте в Проводнике папку проекта, например `C:\Projects\MyFirstProject`.
3. Откройте эту папку в Проводнике. Щёлкните в адресной строке, введите `powershell` и нажмите Enter.
4. В открывшемся окне выполните:

   ```powershell
   agentboard init
   agentboard open
   ```

5. Откроется браузер с адресом `http://127.0.0.1:7337`. Оставьте окно PowerShell открытым, пока используете доску. Закрытие окна остановит локальный сервер, но задачи сохранятся.

Если команда `agentboard` не найдена, закройте PowerShell и откройте заново после установки Scoop. При установке из ZIP используйте полный путь к `agentboard.exe`.

## Первая задача

Нажмите **New task**, заполните **Title**, при необходимости **Description**, затем **Save**. Новая задача в `Backlog` доступна человеку. Чтобы AI приступил к работе, назначьте воркера и перенесите задачу в `Features`. Пошаговое описание полей — [TASKS.md](TASKS.md).

## Первый воркер

Откройте **Workers → Add worker**. Выберите используемый AI-клиент (например Codex или Claude Code), проверьте имя и короткий идентификатор `Slug`, нажмите **Save**. Откройте созданного воркера: там есть MCP-конфигурация, кнопка копирования и проверка сервера. Скопируйте конфигурацию в AI-клиент согласно [WORKERS_MCP.md](WORKERS_MCP.md). После подключения попросите клиента вызвать `get_my_board`.
