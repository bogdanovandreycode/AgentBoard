# Импорт задач из JSON

Вкладка **Import tasks** принимает файл JSON в кодировке UTF-8. Используйте её, если переносите задачи из другого сервиса. Нажмите **Download JSON template**: шаблон включает текущие имена пользовательских свойств и `Slug` доступного воркера этого проекта.

## Пошагово

1. Создайте необходимые воркеры (**Workers**) и свойства (**Properties**) до импорта.
2. Скачайте шаблон, откройте его в текстовом редакторе, замените примеры своими задачами и сохраните файл с расширением `.json`.
3. На вкладке **Import tasks** выберите файл. Интерфейс покажет количество задач.
4. Нажмите **Import tasks**. Сервер проверит весь файл: если обнаружится ошибка, ни одна задача из него не будет записана. Исправьте сообщение об ошибке и повторите.

Минимальный файл:

```json
{
  "version": 1,
  "tasks": [
    { "title": "Составить план проекта" },
    { "title": "Проверить результат", "state": "features", "priority": "high" }
  ]
}
```

Пример с воркером, свойством и зависимостью:

```json
{
  "version": 1,
  "tasks": [
    {
      "key": "design",
      "title": "Подготовить дизайн",
      "description": "## Цель\nПодготовить макет главной страницы.",
      "state": "features",
      "priority": "high",
      "testing_mode": "hybrid",
      "assignee": { "type": "worker", "worker": "codex" },
      "ai_test_instructions": "Проверить сборку.",
      "human_test_instructions": "Проверить внешний вид в браузере.",
      "properties": { "Department": "Design" }
    },
    {
      "title": "Утвердить дизайн",
      "depends_on": ["design"],
      "assignee": { "type": "human" }
    }
  ]
}
```

`version` должен быть `1`, массив `tasks` — от 1 до 1000 задач. `title` обязателен. Допустимые этапы: `backlog`, `features`, `in_progress`, `testing`, `verification`, `complete`. Приоритеты: `critical`, `high`, `medium`, `low`; режимы проверки: `ai`, `human`, `hybrid`. Ответственный: `unassigned`, `human` или `worker` с существующим `worker` (Slug либо ID). `properties` использует имена или ID уже созданных свойств. `key` уникален внутри файла; `depends_on` ссылается на такие ключи. ID задач сервер создаёт сам.

Повторный импорт того же файла создаст новые задачи, поэтому перед повторным нажатием проверьте доску. При импорте задачи записываются как созданные человеком; в истории появляется системная запись.
