# 작업 작업

## 작업 추가

**보드** 탭에서 **새 작업**을 클릭합니다. 제목과 설명을 입력하세요. 설명 및 테스트 지침은 Markdown을 지원합니다. 텍스트를 강조 표시하고 굵게, 기울임꼴, 링크 및 목록에 서식 지정 막대를 사용합니다. **저장**을 클릭합니다.

분야:

| 필드 | 무엇을 하는가 |
| --- | --- |
| 제목 | 작업의 짧은 이름입니다. |
| 설명 | 수행해야 할 작업과 작업이 준비되었음을 이해하는 방법. |
| 상태 | 작업단계; 새 작업은 일반적으로 `Backlog`에서 시작됩니다. |
| 우선순위 | `critical`, `high`, `medium` 또는 `low`. |
| 책임 | 사람, 특정 근로자 또는 약속이 없는 사람. |
| 테스트 모드 | `AI` - AI를 확인합니다. `Human` - 인간 수표; `Hybrid` - 둘 다. |
| 종속성 | 더 일찍 완료해야 하는 작업입니다. |
| AI/인간 테스트 지침 | 적절한 검토자에게 지침을 제공합니다. |
| 사용자 정의 속성 | **속성** 탭에 추가 필드가 생성되었습니다. |

AI 작업의 경우 먼저 작업자를 생성하고 Responsible에서 선택한 다음 카드를 `Features`로 전송합니다. AI는 `Features`부터 `Verification`까지 4단계로 할당된 작업만 볼 수 있습니다.

## 작업 이동

열 사이에 카드를 드래그합니다. 가로 스크롤을 사용하여 전체 열 보기와 넓은 열 간에 전환할 수 있습니다. `Backlog` 및 `Complete`는 인간이 제어합니다. AI는 특수 MCP 도구를 통해서만 작업 `Features → In progress → Testing → Verification`를 진행할 수 있습니다. 완료되지 않은 수동 테스트가 있는 작업은 AI 검증을 통과해서는 안 됩니다.

## 작업 카드

카드를 클릭하면 설명, 소유자, 테스트 지침, 기록 탭, 테스트, 아티팩트, AI 비용을 볼 수 있습니다. **작업 편집**은 내용을 변경합니다. 그 사람의 댓글이 전체 스토리에 추가됩니다. 제목, 설명, ID 및 작업자별로 상단 필터를 검색합니다. 별도의 버튼을 누르면 대규모 검색이 열립니다.

## 열 및 속성

**설정** 탭에서 개인이 사용할 수 있는 열 순서를 변경하고 자신만의 열을 추가할 수 있습니다. 4개의 AI 단계는 고정되어 있으며 동일한 순서로 진행됩니다. 사용자 열은 사람이 연기한 작업을 위한 장소입니다. AI의 경우 해당 작업의 상태는 `Backlog`입니다. 열이 삭제되면 해당 작업이 일반 `Backlog`로 돌아갑니다.

**속성** 탭에서 텍스트, 숫자, 플래그, 날짜, 선택 항목, URL 등의 필드를 추가할 수 있습니다. `Human only`는 AI로부터 필드를 숨깁니다. `Agent read`는 읽기를 허용하고, `Agent read/write`는 지원되는 도구를 통해 쓰기도 허용합니다. 이는 작업 단계에 대한 AI의 권한을 변경하지 않습니다.
