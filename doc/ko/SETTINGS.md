# 설정

선택한 프로젝트의 사이드 메뉴에서 **설정**을 엽니다. 변경 사항은 **설정 저장** 버튼을 사용하여 저장되고 AgentBoard 데이터베이스의 프로젝트에 저장됩니다.

## 언어 및 외관

**언어** 필드는 검색 드롭다운 목록을 엽니다. 기본적으로 브라우저 언어를 사용하는 **시스템 따르기** 옵션이 선택되어 있습니다. 스크린샷에서 사용 가능한 언어: 아랍어, 포르투갈어(브라질), 중국어 간체, 체코어, 덴마크어, 네덜란드어, 영어, 핀란드어, 프랑스어, 독일어, 이탈리아어, 일본어, 한국어, 노르웨이어 보크몰어, 폴란드어, 러시아어, 스페인어, 스웨덴어, 터키어, 우크라이나어, 베트남어; 추가로 벨로루시어, 루마니아어, 불가리아어. **팔로우 시스템**은 브라우저 언어를 사용합니다. 기본 서명은 수동으로 번역되고, 나머지 UI 줄은 예비 자동 번역됩니다. 공개되기 전에 원어민의 번역을 교정하는 것이 좋습니다. 클라이언트 이름, 명령, JSON 필드 및 사용자 데이터는 번역되지 않은 상태로 유지됩니다.

**색 구성표**: 어두운(원래 테마), 밝은, 검은색, Ubuntu 및 Windows. **시간대**는 날짜 표시를 제어합니다. 데이터는 UTC로 계속 저장됩니다. **시스템 시간대**는 컴퓨터 설정을 사용합니다.

## 열

4개의 스테이지 `Features`, `In progress`, `Testing`, `Verification`는 이 순서대로 고정되어 있으며 이름을 바꾸거나 삭제할 수 없습니다. 사용 가능한 화살표를 사용하여 다른 열을 다시 정렬할 수 있습니다. 이름을 입력하고 **열 추가**를 클릭하여 맞춤 열을 만듭니다. 인간 작업을 위해 설계되었습니다. AI는 `Backlog`와 같은 작업을 보고 MCP를 통해 수신하지 않습니다. 저장하는 동안 열을 삭제하면 해당 작업이 일반 `Backlog`로 전송됩니다.

## 웹과 MCP

**보드 새로 고침**은 보드와 카드의 새로 고침 빈도를 초(1~60) 단위로 설정합니다. **작업자 새로 고침**은 작업자 상태를 업데이트합니다(2~120초). 이는 AI 트리거 빈도가 아닌 웹 인터페이스 폴링입니다. 작업자는 자동으로 시작되지 않습니다.

웹 서버 주소는 CLI를 시작할 때 설정됩니다(예: `agentboard open --addr 127.0.0.1:7444`). 주소를 변경하려면 서버를 다시 시작해야 합니다. 기본값은 `127.0.0.1:7337`입니다. MCP는 별도의 로컬 명령 `agentboard mcp --project ... --worker ...`를 통해 작동하며 웹 포트와 독립적입니다. 비표준 베이스의 경우 모든 명령에 동일한 `--db`를 지정하십시오. 작업자 카드에서 각 클라이언트의 구성을 복사합니다.
