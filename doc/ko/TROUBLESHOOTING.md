# 문제 해결

| 증상 | 확인해야 할 사항 |
| --- | --- |
| `agentboard`를 찾을 수 없습니다 | Scoop 후에 PowerShell을 다시 시작합니다. ZIP에서 설치하는 경우 `agentboard.exe`의 전체 경로를 사용하세요. |
| 빌드 후 이전 인터페이스를 보여주는 웹 페이지 | 실행 중인 서버를 중지합니다. Ctrl+C. `./scripts/build.ps1`를 실행하고 새 바이너리를 시작하십시오. 인터페이스가 EXE에 내장되어 있으므로 Vite는 Go보다 먼저 빌드해야 합니다. Ctrl+F5 페이지를 새로 고칩니다. |
| 포트 7337 사용 중 | AgentBoard가 이미 실행 중일 수 있습니다. `http://127.0.0.1:7337`를 열거나 이전 프로세스를 종료하세요. 다른 포트의 경우 `--addr`를 사용하십시오. |
| 프로젝트를 찾을 수 없습니다 | 원하는 폴더에서 `agentboard init`를 실행하세요. 그런 다음 `agentboard open` 또는 `agentboard open C:\путь\к\проекту`. |
| 작업자가 작업을 볼 수 없습니다 | 작업은 이 특정 작업자에게 할당되어야 하며 `Features`, `In progress`, `Testing` 또는 `Verification`에 위치해야 합니다. AI는 `Backlog`, `Complete` 및 사용자 정의 열을 표시하지 않습니다. |
| MCP 서버 검사가 존재하지만 클라이언트가 연결되어 있지 않습니다. | 서버 확인에서는 외부 클라이언트 설정을 확인하지 않습니다. 클라이언트를 다시 시작하고 해당 구성 파일, `agentboard.exe`, `--project`, `--worker` 및 일반 `--db`에 대한 경로를 확인하세요. `get_my_board`에 전화해 달라고 요청하세요. |
| 작업자 오프라인 | 클라이언트가 종료되었거나 아직 MCP를 시작하지 않았을 수 있습니다. 하트비트 없이 90초가 지나면 세션 연결이 끊어진 것으로 간주됩니다. |
| JSON 파일을 가져오지 않음 | `version: 1`, 필수 `title`, 기존 `Slug` 작업자 및 속성 이름을 확인하세요. JSON은 주석이나 후행 쉼표를 허용하지 않습니다. |
| `agentboard.exe`를 재구축할 수 없습니다. | Windows는 실행 중인 EXE를 바꿀 수 없습니다. 서버 Ctrl+C를 중지하고 빌드를 다시 시도하십시오. |
| 업데이트 후 작업이 사라졌습니다 | `--db`가 다른 파일을 가리키지 않는지, 동일한 Windows 사용자로 로그인했는지 확인하십시오. 기본 베이스는 `%AppData%\AgentBoard`에 있습니다. |

오류가 설명되지 않은 경우 메시지의 정확한 텍스트, `agentboard version` 및 Windows 버전, 재시도 단계를 수집하세요. 비공개 프로젝트 데이터나 데이터베이스 콘텐츠를 공개 이슈에 게시하지 마세요.
