# 여기서 시작하세요

## AgentBoard란 무엇입니까?

작업 카드가 있는 일반 보드를 상상해 보세요. 작업을 생성하고 책임자를 지정하고 작업을 감독합니다. AI 작업자는 MCP를 통해 할당된 작업만 받고 진행 상황을 보고합니다. 작업이 최종적으로 준비되는 시점을 결정합니다.

**프로젝트** - 컴퓨터의 폴더이자 별도의 보드입니다. **과제** - 설명, 책임자, 단계가 적힌 카드입니다. **Worker**는 AI 클라이언트의 논리적 이름입니다. **MCP**는 AI 클라이언트가 AgentBoard에 연결하는 방식입니다. **Scoop**은 Windows용 소프트웨어 설치 관리자입니다.

코드가 필요하지 않습니다. AI가 작동하려면 Windows, 브라우저, PowerShell이 ​​필요하며 로컬 MCP 서버를 지원하는 AI 클라이언트가 설치되어 있어야 합니다.

## 첫 출시

1. [지침](INSTALL.md).dll]에 따라 애플리케이션을 설치합니다.
2. Explorer에서 프로젝트 폴더(예: `C:\Projects\MyFirstProject`)를 생성합니다.
3. 탐색기에서 이 폴더를 엽니다. 주소 표시줄을 클릭하고 `powershell`를 입력한 후 Enter를 누르세요.
4. 열리는 창에서 다음을 수행하십시오.

```powershell
agentboard init
agentboard open
```

5. `http://127.0.0.1:7337` 주소로 브라우저가 열립니다. 화이트보드를 사용하는 동안 PowerShell 창을 열어두세요. 창을 닫으면 로컬 서버가 중지되지만 작업은 그대로 유지됩니다.

`agentboard` 명령을 찾을 수 없으면 PowerShell을 닫고 Scoop을 설치한 후 다시 엽니다. ZIP에서 설치하는 경우 `agentboard.exe`의 전체 경로를 사용하세요.

## 첫 번째 작업

**새 작업**을 클릭하고 **제목**을 입력하고 필요한 경우 **설명**을 입력한 다음 **저장**을 입력합니다. `Backlog`의 새로운 작업을 인간이 사용할 수 있습니다. AI가 작업을 시작하려면 작업자를 할당하고 작업을 `Features`로 전송합니다. 필드에 대한 단계별 설명 - [TASKS.md](TASKS.md).

## 첫 번째 작업자

**작업자 → 작업자 추가**를 엽니다. 사용 중인 AI 클라이언트(예: Codex 또는 Claude Code)를 선택하고 이름과 단축 ID `Slug`를 확인한 후 **저장**을 클릭하세요. 생성된 작업자를 엽니다. MCP 구성, 복사 버튼 및 서버 확인이 있습니다. [WORKERS_MCP.md](WORKERS_MCP.md)에 따라 구성을 AI 클라이언트에 복사합니다. 연결되면 클라이언트에게 `get_my_board`를 호출하도록 요청하세요.
