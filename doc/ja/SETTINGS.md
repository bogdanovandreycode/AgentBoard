# 設定

選択したプロジェクトのサイド メニューで [**設定**] を開きます。変更は [**設定の保存**] ボタンで保存され、AgentBoard データベース内のプロジェクトに保存されます。

## 言語と外見

**言語** フィールドを選択すると、検索ドロップダウン リストが開きます。デフォルトでは、**システムに従う** オプションが選択されており、ブラウザ言語が使用されます。スクリーンショットから利用可能な言語: アラビア語、ポルトガル語 (ブラジル)、簡体字中国語、チェコ語、デンマーク語、オランダ語、英語、フィンランド語、フランス語、ドイツ語、イタリア語、日本語、韓国語、ノルウェー語 (ブークモール)、ポーランド語、ロシア語、スペイン語、スウェーデン語、トルコ語、ウクライナ語、ベトナム語。さらにベラルーシ人、ルーマニア人、ブルガリア人もいます。 **システムに従ってください** はブラウザ言語を受け取ります。主要な署名は手動で翻訳され、残りの UI 行には予備的な自動翻訳が行われます。公開する前に、ネイティブ スピーカーによる翻訳の校正を行うことをお勧めします。クライアント名、コマンド、JSON フィールド、ユーザー データは変換されずに残ります。

**カラースキーム**: ダーク (オリジナルのテーマ)、ライト、ブラック、Ubuntu、Windows。 **タイムゾーン**は日付の表示を制御します。データは引き続き UTC で保存されます。 **システムのタイムゾーン**はコンピュータの設定を使用します。

## 列

`Features`、`In progress`、`Testing`、`Verification` の 4 つのステージはこの順序で固定されており、名前の変更や削除はできません。他の列は、使用可能な矢印を使用して再配置できます。名前を入力し、[**列を追加**] をクリックしてカスタム列を作成します。これは人間のタスク向けに設計されています。AI は `Backlog` のようなタスクを認識しますが、MCP を通じてそれを受け取りません。保存中に列を削除すると、そのタスクが通常の `Backlog` に転送されます。

## ウェブと MCP

**ボードのリフレッシュ** は、ボードとカードのリフレッシュ レートを秒単位 (1 ～ 60) で設定します。 **ワーカーの更新** は、ワーカーのステータスを更新します (2 ～ 120 秒)。これは Web インターフェイスのポーリングであり、AI トリガーの頻度ではありません。ワーカーは自動的に起動しません。

Web サーバーのアドレスは、CLI の起動時に設定されます (例: `agentboard open --addr 127.0.0.1:7444`)。アドレスを変更するには、サーバーを再起動する必要があります。デフォルトは`127.0.0.1:7337`です。 MCP は、別のローカル コマンド `agentboard mcp --project ... --worker ...` を通じて動作し、Web ポートから独立しています。非標準ベースの場合は、すべてのコマンドで同じ `--db` を指定します。各クライアントの設定をワーカー カードからコピーします。
