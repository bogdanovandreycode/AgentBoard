# 問題解決

|症状 |何を確認するか |
| --- | --- |
| `agentboard` が見つかりません | Scoop 後に PowerShell を再起動します。 ZIP からインストールする場合は、`agentboard.exe` へのフルパスを使用します。 |
|ビルド後の古いインターフェイスを表示する Web ページ |実行中のサーバーを停止します Ctrl+C。 `./scripts/build.ps1` を実行し、新しいバイナリを起動します。インターフェイスは EXE に組み込まれているため、Vite は Go の前にビルドする必要があります。ページを更新するには Ctrl+F5 を押します。 |
|ポート 7337 がビジーです | AgentBoard がすでに実行されている可能性があります。 `http://127.0.0.1:7337` を開くか、古いプロセスを終了します。他のポートの場合は、`--addr` を使用します。 |
|プロジェクトが見つかりません |目的のフォルダーで、`agentboard init` を実行します。次に、そこからの `agentboard open` または `agentboard open C:\путь\к\проекту`。 |
|ワーカーにはタスクが表示されません |タスクはこの特定のワーカーに割り当てられ、`Features`、`In progress`、`Testing`、または `Verification` に配置される必要があります。 AI は、`Backlog`、`Complete`、およびカスタム列を認識しません。 |
| MCP サーバー チェックは存在しますが、クライアントは接続されていません。サーバーチェックでは、外部クライアント設定はチェックされません。クライアントを再起動し、その構成ファイル、`agentboard.exe`、`--project`、`--worker`、および一般的な `--db` へのパスを確認します。 `get_my_board` に電話してもらいます。 |
|オフラインのワーカー |クライアントが終了したか、MCP がまだ開始されていない可能性があります。ハートビートが 90 秒ないと、セッションは切断されたとみなされます。 |
| JSON ファイルがインポートされない | `version: 1`、必須の `title`、既存の `Slug` ワーカーとプロパティ名を確認します。 JSON では、コメントや末尾のカンマは許可されません。 |
| `agentboard.exe` を再構築できません | Windows では、実行中の EXE を置き換えることはできません。サーバー Ctrl+C を停止し、ビルドを再試行します。 |
|アップデート後にタスクが消えた | `--db` が別のファイルを指していないか、同じ Windows ユーザーとしてログインしていることを確認してください。デフォルトのベースは `%AppData%\AgentBoard` です。 |

エラーが説明されていない場合は、メッセージの正確なテキスト、`agentboard version` と Windows のバージョン、および再試行する手順を収集してください。非公開のプロジェクト データやデータベースの内容を未解決の問題で公開しないでください。
