# ここから始めましょう

## AgentBoard とは

タスク カードを備えた通常のボードを想像してください。タスクを作成し、責任者を割り当てて、作業を監督します。 AI ワーカーは、割り当てられたタスクのみを MCP 経由で受け取り、進捗状況を報告します。タスクの最終的な準備がいつ完了するかを決めるのはあなたです。

**プロジェクト** - コンピューター上のフォルダーと別のボード。 **タスク** - 説明、責任者、段階が記載されたカード。 **Worker** は AI クライアントの論理名です。 **MCP** は、AI クライアントが AgentBoard に接続する方法です。 **Scoop** は、Windows 用のソフトウェア インストール マネージャーです。

コードは必要ありません。 AI が動作するには、Windows、ブラウザー、PowerShell、およびローカル MCP サーバーをサポートする AI クライアントがインストールされている必要があります。

## 最初の起動

1. 「取扱説明書](INSTALL.md)」に従ってアプリケーションをインストールします。
2. エクスプローラーでプロジェクト フォルダー (例: `C:\Projects\MyFirstProject`) を作成します。
3. エクスプローラーでこのフォルダーを開きます。アドレス バーをクリックし、「`powershell`」と入力して Enter キーを押します。
4. 開いたウィンドウで次の操作を行います。

```powershell
agentboard init
agentboard open
```

5. アドレス `http://127.0.0.1:7337` でブラウザが開きます。ホワイトボードを使用している間、PowerShell ウィンドウを開いたままにしてください。ウィンドウを閉じるとローカル サーバーは停止しますが、タスクは残ります。

コマンド `agentboard` が見つからない場合は、PowerShell を閉じて、Scoop のインストール後に再度開きます。 ZIP からインストールする場合は、`agentboard.exe` へのフルパスを使用します。

## 最初のタスク

**新しいタスク**をクリックし、**タイトル**、必要に応じて**説明**を入力し、**保存**します。 `Backlog` の新しいタスクを人間が利用できるようになりました。 AI が動作を開始するには、ワーカーを割り当て、タスクを `Features` に転送します。フィールドのステップごとの説明 - [TASKS.md](TASKS.md).

## 最初のワーカー

**[ワーカー] → [ワーカーの追加]** を開きます。使用している AI クライアント (Codex や Claude Code など) を選択し、名前と短縮 ID `Slug` を確認し、**保存** をクリックします。作成したワーカーを開きます。MCP 設定、コピー ボタン、サーバー チェックがあります。 [WORKERS_MCP.md](WORKERS_MCP.md)] に従って、構成を AI クライアントにコピーします。接続したら、クライアントに `get_my_board` に電話するよう依頼します。
